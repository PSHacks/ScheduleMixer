# Schedule 1 Mixer 💊

This tool helps you create and analyze drug mixes in a popular game 🎮. Select your base product, add substances, and see the effects, profit, and addiction potential of your mix! Perfect for optimizing your in-game drug production.

## Features ✨
- **Dark theme** for comfortable night sessions 🌙
- **Drag & Drop interface** for easy substance mixing ✋
- **Bilingual support** (English/Russian WIP) 🌍
- **Detailed results** showing:
  - Effects with visual badges 🏷️
  - Total cost and profit 💰
  - Addiction potential ⚠️
- **Smart calculation** that accounts for substance interactions 🧠

## How to Use 🔧
1. **Select your base product** from the dropdown 🏷️
2. **Drag substances** from "Available" to "Selected Mix" 🖱️
   - Max 8 substances per mix
   - Reorder by dragging in the selected list
3. **Click "Calculate Mix"** to see results 📊
4. **Analyze** the effects, profit, and addiction 🧐

## Example Mix 🧪
- **Base Product**: OG Kush
- **Substances**: 
  - Cuke (+Energizing)
  - Flu Medicine (+Sedating → Bright-Eyed)
  - Iodine (+Jennerising)
- **Results**:
  - Effects: Bright-Eyed, Jennerising
  - Profit: $42 (28% margin)
  - Addiction: 34%

## How to Run 🏃‍♂️
1. Download or clone the repo
2. Open `index.html` in any modern browser
3. Start mixing! No server required 🚀
